# Instalación

## 1. Inicializar el proyecto

```bash
npm init -y
```

## 2. Instalar dependencias

```bash
npm install mysql2
```

## 3. (Opcional) Instalar nodemon para desarrollo

```bash
npm install --save-dev nodemon
```

## 4. Ejecutar la aplicación

```bash
node main.js
```

O si utilizas **nodemon**:

```bash
npx nodemon main.js
```
